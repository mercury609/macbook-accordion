# Third-party components

Keyboard layout and sensor approach reference: MacacaGames/MacbookAccordion (MIT), https://github.com/MacacaGames/MacbookAccordion . This application uses newly implemented bellows and synthesis modules.

Transcription: Spotify Basic Pitch 0.4.0, Apache-2.0, https://github.com/spotify/basic-pitch . Uses the bundled ICASSP 2022 ONNX model.

Optional vocal isolation: Demucs 4.1.0 (MIT), https://github.com/adefossez/demucs . The htdemucs model is distributed by Meta at https://dl.fbaipublicfiles.com/demucs/hybrid_transformer/955717e8-8726e21a.th .

Runtime components include Python (PSF), NumPy (BSD), pygame (LGPL), PortAudio/sounddevice (MIT), pybooklid (MIT), ONNX Runtime (MIT), librosa (ISC), SciPy (BSD), PyTorch (BSD), FFmpeg (its bundled binary's license applies). Original notices are included under licenses/ and in the application bundle's package metadata where available.
